# 明心同行 Android 项目

这个版本是在原来的 `明心之眼` Android 代码基础上整理的，不是重新造一个空项目。

## 这次调整做了什么

1. 根目录改成英文 `MingXinTongXing`，避免解压后出现乱码文件夹。
2. 删除了旧的 Fragment/XML 页面残留，保留 Compose 主流程。
3. 首页改成：开始出行、问一下/快速识别、社区互助、心理支持、长辈模式与设置。
4. 增加全局 SOS 按钮，任何页面右下角都能进入紧急求助。
5. 增加明心之眼出行流程页面骨架：
   - 询问目的地
   - 出行前检查
   - 个性化出行方案
   - 出行陪伴
   - 问一下/快速识别
6. 按模块重新分类文件夹，方便 6 个成员分工。

## 重要说明

现在完成的是“结构整理 + 主流程骨架 + 模块分类”。

还没有真正接入的部分：

- 真实地图 SDK
- 真实摄像头出行扫描
- 真实物体识别模型
- 真实 AI 心理接口
- 真实后端服务
- 高铁站/机场官方系统接口

这些需要对应成员继续在各自文件夹中开发。
